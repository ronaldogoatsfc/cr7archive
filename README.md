# The Ronaldo Archive

The Ronaldo Archive is an unofficial, fan-made archive exploring Cristiano Ronaldo's career through match logs, statistics, visualizations, articles, trophies, individual honors, and records.

## Technology

- Next.js (App Router)
- React
- Tailwind CSS
- Recharts

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

- `app/` — website pages, layout, styles, and sitemap
- `components/` — shared interface components
- `data/` — match records, articles, honors, trophies, and other archive data
- `lib/` — shared data and statistics helpers
- `public/` — static assets

## Data and methodology

The archive is maintained as a fan project. Match and statistical records may vary in availability by season, competition, and source. Where data is incomplete, comparisons and summaries should be interpreted with that limitation in mind.

## Deployment

The project is configured for Next.js and can be deployed to a compatible hosting provider such as [Vercel](https://vercel.com).
